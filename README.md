# MAJ Vision

Statická verzia portfólia pripravená pre GitHub Pages.

## Publikovanie cez GitHub Pages

1. Na GitHube vytvor nový verejný repozitár, napríklad `majvision`.
2. Nahraj doň celý obsah tohto balíka, nie nadradený priečinok.
3. V repozitári otvor **Settings → Pages**.
4. V časti **Build and deployment** vyber **GitHub Actions**.
5. Po dokončení nasadenia sa web zobrazí na adrese uvedenej v sekcii Pages.

## Vlastná doména

Vlastnú doménu `majvision.com` nastav až po úspešnom zobrazení webu na GitHub Pages. DNS záznamy sa potom musia zmeniť z aktuálneho hostingu na hodnoty, ktoré zobrazí GitHub v nastavení Pages.

## Kontaktný formulár

Formulár posiela správy na `light@majvision.com` cez FormSubmit. Po prvom skúšobnom odoslaní treba v tejto schránke potvrdiť aktivačný e-mail od FormSubmit.
